# 커리어 웨이브 Career Wave React UI

AI 기반 취업 준비 올인원 플랫폼 **커리어 웨이브**의 React 프론트엔드 초안입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 알려주는 주소로 접속하세요.

## 디자인 방향

- 파스텔 블루 중심
- 미색 배경
- 톤다운된 블루 그레이 텍스트
- 둥근 카드형 SaaS 대시보드 UI
- 취업 준비생이 편안하게 사용할 수 있는 UI/UX

## 주요 도메인

1. Auth & Member
2. Company
3. Job Notice
4. Application & Matching
5. Dashboard
6. Document Analysis
7. Interview
8. Community
9. Billing & Payment
